## 贝叶斯定理

```
P(类别|特征) = P(特征|类别)·P(类别) / P(特征)
```

分类时选后验概率最大的类别：

```
ŷ = argmax_c P(c|x) = argmax_c P(x|c)·P(c)
```

## 「朴素」独立假设

真实情况下特征之间往往相关，直接算 P(x|c) 很难。朴素贝叶斯假设「给定类别后，各特征独立」：

```
P(x|c) = P(x_1|c)·P(x_2|c)·...·P(x_n|c)
```

于是问题分解成「每个特征单独算条件概率再相乘」，训练和推断都极快。

## 优缺点

- **优点**：简单、快、样本需求少、高维下表现不错，适合文本分类（垃圾邮件过滤）；
- **缺点**：独立假设现实中常不成立，且对连续特征的概率估计方式敏感。

## 面试加分点 / 追问方向

- 为什么假设「不成立」还这么好用：虽然概率估计不准，但「相对排序」往往是对的；
- 三种变体：高斯（连续）、多项式（计数/文本）、伯努利（0/1）。
