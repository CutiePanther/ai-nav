## 为什么需要虚拟内存

1. **隔离与安全**：每个进程看到独立的地址空间，互不干扰，防越界访问；
2. **内存抽象**：进程可用比物理内存更大的「虚拟」空间，未用到的部分不占物理内存；
3. **简化编程**：进程认为内存连续，实际由页表映射到分散的物理页。

## 关键机制

- **页表 + TLB**：虚拟地址 → 物理地址的映射表；TLB 缓存最近映射加速查询；
- **页表分级**：多级页表节省页表本身的内存占用；
- **缺页中断**：访问的页不在物理内存时，CPU 触发缺页异常，由内核换入页面（从磁盘/交换区）。

## 页面置换算法

| 算法 | 思想 | 缺点 |
| --- | --- | --- |
| FIFO | 淘汰最早进入的页 | 可能出现 Belady 异常 |
| LRU | 淘汰最久未使用的页 | 实现需额外结构 |
| 时钟（Clock） | LRU 的近似，用访问位轮转 | 近似但开销小 |

## 面试加分点 / 追问方向

- **虚拟地址到物理地址的转换过程**：分段 → 查页表（TLB 命中）→ 组合页框与偏移；
- **缺页异常处理流程**：陷入内核 → 判断地址合法 → 找空闲页框 → 磁盘换入 → 更新页表 → 恢复执行；
- **写时复制（COW）**：fork 后父子共享只读页，写时才复制，Linux 常见优化。
