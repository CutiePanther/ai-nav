## 为什么需要记忆

LLM 是「无状态」的：每次调用只看当前输入，不记得上一轮说了什么。要实现多轮对话、个性化，就需要在外部维护记忆。

## 三层记忆

1. **短期记忆（上下文窗口内）**：把历史消息按顺序拼进 prompt。最简单，但受窗口长度限制，且随轮数增长 token 成本上升；
2. **长期记忆（外部存储 + 检索）**：把重要信息写入向量库/数据库，需要时检索回来。适合跨会话、大信息量的记忆；
3. **摘要记忆**：对历史对话做「滚动摘要」，把冗长历史压成一段摘要放进上下文，节省 token。

## 工程实现要点

- **滑动窗口 + 摘要**：保留最近 N 轮原文，更早的压缩成摘要；
- **记忆检索**：用 embedding 把历史记忆向量化，按相关度取回 top-k；
- **淘汰策略**：记忆需要「遗忘」，否则会越积越多、检索变慢、成本上升。

## 面试加分点 / 追问方向

- 说清「拼上下文」是最基础也最常用的短期记忆，且和 token 成本强相关；
- Agent 里常需要「结构化记忆」：事实、偏好、任务进度分开存，而不是一股脑拼文本。
