## 三大组件

1. **视觉编码器**：用 ViT / CLIP 视觉塔把图像编码成视觉特征（token）。参数通常被冻结或单独训练；
2. **对齐模块（Projector）**：用一个 MLP/线性层把视觉特征「投影」到文本 token 的向量空间，让 LLM 能「看懂」；
3. **大语言模型**：接收「图像 token + 文本 token」一起做自回归，完成图文问答、描述、OCR 等任务。

## 训练流程

- **阶段一（预训练对齐）**：冻结视觉塔和 LLM，只训练 projector，用大量图文对做「图文对齐」；
- **阶段二（指令微调）**：解冻部分/全部参数，用多模态指令数据做 SFT，让模型会「看图回答」。

## 为什么这样设计

- 复用强大的 LLM 和成熟的视觉编码器，不必从头训练；
- 只需训练轻量的对齐模块 + 微调，成本可控；
- 图像被「token 化」后，就能和文本一样进入 Transformer 统一处理。

## 面试加分点 / 追问方向

- 为什么用「投影到文本空间」而不是直接拼接（维度不匹配、语义空间不同）；
- 视觉 token 数量的影响：高分辨率图会产生大量视觉 token，成本高，所以有动态分辨率、token 压缩等优化。
