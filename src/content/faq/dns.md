## 完整解析流程

1. **浏览器缓存**：先查浏览器自身的 DNS 缓存；
2. **系统缓存 + hosts 文件**：查操作系统缓存和本地 hosts 配置；
3. **本地 DNS 服务器**（递归查询）：如运营商或路由器配置的 DNS；
4. **根域名服务器**：返回顶级域（.com/.cn）服务器地址；
5. **顶级域服务器**：返回权威域名服务器地址；
6. **权威域名服务器**：返回最终 IP，逐级缓存回传。

## 递归查询 vs 迭代查询

- **递归查询**：客户端 → 本地 DNS，本地 DNS 替你问到底，返回最终结果；
- **迭代查询**：本地 DNS → 根/顶级/权威，逐级「我给你线索，你自己去问下一级」。

## 面试加分点 / 追问方向

- **CDN 与 DNS**：权威 DNS 根据用户 IP 返回就近节点，实现智能调度；
- **DNS 污染/劫持**：解析结果被篡改，可用 DoH/DoT 加密 DNS 缓解；
- **DNS 负载均衡**：同一域名返回多个 IP，客户端随机/轮询选择。
