## 为什么要 warmup

训练初期：

- 模型参数随机初始化，梯度方向不稳定、方差大；
- 如果一开始就用大学习率，参数容易被「带偏」，甚至早期就落入不好的局部区域，损失剧烈震荡或发散。

warmup 的做法：前 N 步让学习率从接近 0 线性增长到目标值，给模型一个「缓启动」的窗口，等梯度稳定后再放开。

## 常见调度策略

| 策略 | 思路 | 特点 |
| --- | --- | --- |
| 阶梯衰减 | 每隔若干 epoch 学习率乘以一个系数（如 ×0.1） | 简单粗暴 |
| 余弦退火 | 学习率按余弦曲线从峰值衰减到接近 0 | 平滑，主流 |
| 线性衰减 | 线性递减到 0 | 简单 |
| 循环学习率 | 周期性升降，可在周期内重启 | 用于寻找更优解 |

现代大模型训练普遍采用「warmup + 余弦退火」的组合。

## 面试加分点 / 追问方向

- warmup 对 Pre-Norm 架构相对没那么必要（因为 Pre-Norm 本身就稳），这是能体现深度的点；
- 学习率与 batch size 的关系：大 batch 通常配大学习率（线性缩放法则）。
