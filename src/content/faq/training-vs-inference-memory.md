## 训练显存的组成

以 Adam 优化器、混合精度为例，训练一个 P 参数的模型：

- 权重：2P（FP16）+ 2P（FP32 主副本）≈ 4P 字节；
- 梯度：2P 字节；
- 优化器状态：Adam 的动量 + 方差，各 4P（FP32）≈ 8P 字节；
- 激活值：视 batch 和序列长而定，往往是大头。

粗略算，训练显存约为「权重 + 梯度 + 优化器」≈ 16P 字节量级，再叠加激活。

## 推理显存的组成

- 权重：P × 字节数（FP16 为 2P，量化后更小）；
- KV Cache：随序列增长；
- 少量激活。

不需要梯度、优化器状态，所以推理显存远小于训练。

## 面试加分点 / 追问方向

- 能说清 Adam 为什么占显存（动量、方差两份 FP32 状态）；
- 训练降显存手段：梯度检查点（省激活）、ZeRO（省优化器/参数）、混合精度、梯度累积；
- 推理降显存手段：量化、GQA、KV Cache 优化。
