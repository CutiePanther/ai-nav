## 主要风险

- **提示词注入**：用户输入里夹带指令，诱导模型无视 system prompt 或泄露内部信息；
- **越狱攻击（Jailbreak）**：用角色扮演、编码等方式绕过安全限制，让模型输出有害内容；
- **幻觉与有害内容**：模型编造事实、或输出暴力/色情/违规内容；
- **数据隐私**：把用户敏感信息拼进 prompt 时可能被模型「记住」或经第三方 API 泄露。

## 多层防御

1. **对齐训练**：SFT/RLHF 让模型「天生」拒绝有害请求；
2. **输入护栏**：对用户输入做检测（注入、越狱关键词、敏感词）；
3. **输出护栏**：对模型输出做审核（Moderation API、规则 + 分类器）；
4. **权限隔离与最小权限**：工具调用/数据访问按最小权限，敏感操作需人工确认；
5. **对抗测试（Red Teaming）**：上线前用攻击样本测试，持续回流 badcase。

## 面试加分点 / 追问方向

- 说清「对齐」与「护栏」的区别：一个改模型本身，一个在模型外兜底；
- 为什么不能只靠一道防线：攻击手段不断演化，需要纵深防御。
