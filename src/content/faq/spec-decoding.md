## 自回归生成的瓶颈

自回归生成是「一个 token 一个 token」地串行产出，每个 token 都要跑一次完整的大模型前向。虽然单次前向能并行算，但 token 之间无法并行，导致延迟高、GPU 利用率低。

## 投机采样的思路

1. 用一个**小的草稿模型**（draft model）快速自回归生成一串候选 token（如 5 个）；
2. 把这串候选一次性喂给**大模型**（target model），大模型并行验证每个候选 token 的概率；
3. 只要草稿模型和大模型在某个位置预测一致，就接受该 token；遇到不一致就停下，用大模型重新采样，从这个位置继续。

## 为什么能加速

- 大模型一次前向验证了多个 token，把「串行 N 步」压缩成「1 次大模型前向 + N 次小模型前向」；
- 小模型前向极快，整体延迟显著下降；
- 关键是「接受/拒绝」机制保证了输出分布与大模型一致，**质量无损**（这是投机采样区别于普通「蒸馏加速」的核心）。

## 面试加分点 / 追问方向

- 草稿模型的选择：通常用小模型，或用 Medusa 式的「多头并行预测」替代独立草稿模型；
- 接受率决定加速比：草稿与大模型越一致，加速越明显。
